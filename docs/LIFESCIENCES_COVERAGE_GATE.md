# LIFE SCIENCES — COVERAGE GATE

Status: ACTIVE SUBJECT LANE

This file records the launch scope for the Grade 12 Life Sciences drill pack.

## Official topic map used

Paper 1:
- Meiosis
- Reproduction in Vertebrates
- Human Reproduction
- Responding to the Environment (Humans)
- Human Endocrine System
- Homeostasis in Humans
- Responding to the Environment (Plants)
- Human Impact on the Environment

Paper 2:
- DNA: Code of Life
- Meiosis
- Genetics and Inheritance
- Evolution

## Build rule

Questions in the launch pack are original curriculum-aligned drills. They must not be presented as verbatim DBE past-paper questions unless provenance has been individually verified.

Each item must contain English, Afrikaans and isiXhosa learner-facing text, scaffold hint and memorandum.

## Gate

The first Life Sciences launch pack must cover every topic family above before functional testing. Topic-family coverage is not the same as full syllabus certification. A later depth/provenance/language QA pass remains mandatory before the subject can be called fully complete.
